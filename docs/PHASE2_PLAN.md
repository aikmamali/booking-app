# Plan Φάσης 2

Υλοποίηση με τη σειρά, όπως στο `docs/MVP_PLAN.md`. Κάθε βήμα τελειώνει με πράσινα Pint, PHPStan, Pest και commit. Τα IDs παραπέμπουν στην ενότητα 3 του `docs/SPEC.md`.

Εκτός πλάνου μέχρι να κλείσουν οι αποφάσεις της ενότητας 14 (απόφαση 28/11/2026):
- BK-03 (drop-in με πληρωμή) και MB-03 (online αγορά πακέτου): περιμένουν τον πάροχο πληρωμών
- BL-03 (myDATA): περιμένει την απόφαση για τον πάροχο / λογιστή
- Import πελατών και υπολοίπων: περιμένει την απόφαση για τη μεταφορά δεδομένων

## 1. Ασφάλεια προσωπικού (ID-07)
- [ ] TOTP 2FA για το `/admin`, υποχρεωτικό για ρόλους προσωπικού
- [ ] Recovery codes, επαναφορά 2FA από άλλον admin

## 2. Πάγωμα και παράταση συνδρομής (MB-06)
- [ ] `FreezeMembership`, `UnfreezeMembership`, `ExtendMembership` με μετατόπιση λήξης και audit
- [ ] Η παγωμένη συνδρομή δεν χρεώνεται και δεν λήγει (`MembershipSelector`, `ExpireMemberships`)

## 3. Έξοδα (BL-02)
- [ ] `expenses` με κατηγορία, ποσό, ημερομηνία, σημείωση, συνημμένο
- [ ] Filament resource και export

## 4. Σημειώσεις εκπαιδευτή (RP-03)
- [ ] `notes` ανά πελάτη ή κράτηση, με «ορατή στον πελάτη»
- [ ] Οθόνη στο admin και προβολή των ορατών σημειώσεων στον πελάτη

## 5. Μαζικά μηνύματα (CM-03)
- [ ] Φίλτρα κοινού (ενεργή συνδρομή, λήγει σε X μέρες, υπηρεσία), email / SMS μέσω queue
- [ ] Εξαιρούνται όσοι δεν έχουν συναίνεση. Ιστορικό αποστολών

## 6. Μαζικές κρατήσεις (BK-10)
- [ ] Πελάτες × sessions σε ένα βήμα μέσω `BookSession`, αναφορά αποτυχιών ανά γραμμή

## 7. Σεζόν και σταθερές θέσεις (FS-01 έως FS-04)
- [ ] `seasons`, `fixed_seats` με καταστάσεις requested / active / revoked / ended
- [ ] Αίτηση από τον πελάτη, έγκριση ή απόρριψη από τον admin
- [ ] Κρατήσεις σταθερών θέσεων από το `GenerateSessions`, `pending_credits` και `ExpirePendingBookings`
- [ ] Μετρητής συνεχόμενων ακυρώσεων, ειδοποίηση στην N−1, αφαίρεση στην N

## 8. Σκανάρισμα κάρτας (CI-02)
- [ ] Σελίδα σκαναρίσματος με κάμερα στο admin: στοιχεία, κράτηση της ώρας, υπόλοιπο, προειδοποιήσεις
- [ ] Η κράτηση γίνεται `attended`
